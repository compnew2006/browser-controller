# Progressive Disclosure — تقليل توكنز tool definitions بـ90%+

## المشكلة (موثّقة من Anthropic)

حالياً، كل 21 أداة مسجّلة في الـsystem prompt دفعة واحدة (~4200 توكن ثابتة). مقال Anthropic الرسمي يثبت أن هذا هدر: progressive disclosure يقلل التوكنز بـ98.7%.

## الحل: مكياج من 3 طبقات

### الطبقة 1: أداة `browser_tools` (meta tool) — دائماً مرئية

أداة واحدة فقط تظهر دائماً في `tools/list`:
```
browser_tools { action: "search", query: "click a button" }
→ [{ name: "browser_click", summary: "Click an element by ref or selector" },
   { name: "browser_click_text", summary: "Click by visible text" }]
```

**3 إجراءات (actions):**
- `search` — ابحث بالكلمات المفتاحية → رجع name + summary قصير فقط (~20 توكن/أداة)
- `details` — اطلب schema كامل لأداة واحدة → رجع name + description + schema (~200 توكن)
- `list` — اعرض كل الأسماء + ملخصات (~400 توكن بدل 4200)

### الطبقة 2: تعطيل (disable) الـ20 أداة الأخرى افتراضياً

عند بدء التشغيل:
- سجّل `browser_tools` فقط (مفعّلة)
- سجّل الـ20 أداة الأخرى **معطّلة** (`RegisteredTool.disable()`)
- عندما الوكيل يستدعي `browser_tools {action:"details", tool:"browser_click"}`:
  - فعّل `browser_click` (`enable()` + `sendToolListChanged()`)
  - الآن الـMCP client يرى `browser_click` في `tools/list`

### الطبقة 3: الوضع الكامل (opt-in)

أضف `BROWSER_CONTROLLER_FULL_TOOLS=1` env var:
- لو موجود: سجّل كل الأدوات مفعّلة (السلوك الحالي — للتوافق مع الـbackward)
- لو غائب: الوضع التدريجي (الافتراضي الجديد)

## التكلفة: قبل vs بعد

| | قبل | بعد (تدريجي) |
|---|---|---|
| tools/list الأولي | 21 أداة × ~200 توكن = **~4200** | 1 أداة (browser_tools) = **~150** |
| بعد تفاصيل (details) أداة واحدة | (كلها محمّلة) | +1 أداة = **~350** |
| مهمة نموذجية (3-5 أدوات) | ~4200 ثابتة | **~800-1200** (-75%) |

## الملفات المُعدّلة (4 ملفات)

### 1. `mcp-server/src/tools/types.ts` — إضافة `summary` field
```ts
export interface ToolDefinition {
  name: string;
  summary: string;  // جديد: وصف قصير سطر واحد (لـsearch/list)
  description: string;
  inputSchema: ...;
  handler: ...;
  idempotent?: boolean;
  timeoutMs?: number;
}
```

### 2. `mcp-server/src/tools/meta.ts` — أداة browser_tools الجديدة
أداة meta تقبل:
- `{ action: "search", query: string }` — بحث في name + summary
- `{ action: "details", tool: string }` — schema كامل لأداة
- `{ action: "list" }` — كل الأسماء + ملخصات
- المُعالج (handler) يقرأ من `allTools`/`toolMap` (موجود بالفعل، غير مستخدم حاليًا)

### 3. `mcp-server/src/index.ts` — منطق التسجيل الجديد
```ts
// استبدل حلقة التسجيل المسطحة بحلقة تحتفظ بـRegisteredTool handles:
const fullMode = !!process.env.BROWSER_CONTROLLER_FULL_TOOLS;
const toolHandles = new Map<string, RegisteredTool>();

// 1. سجّل browser_tools أولاً (دائماً مفعّلة)
const metaTool = server.tool('browser_tools', ...);

// 2. سجّل بقية الأدوات
for (const tool of allTools) {
  const handle = server.tool(tool.name, ...);
  if (!fullMode) handle.disable(); // معطّلة افتراضياً
  toolHandles.set(tool.name, handle);
}

// 3. مرّر toolHandles لمُعالج (handler) browser_tools ليفعّل عند الطلب
```

### 4. تحديث الـ21 ملف أداة — إضافة `summary`
كل ملف أداة يحصل على سطر واحد:
```ts
export const clickTool: ToolDefinition = {
  name: 'browser_click',
  summary: 'Click an element by ref or CSS selector',  // جديد
  description: '...',  // موجود
  ...
};
```

## الاختبارات

- اختبار registry جديد: يتحقق من وجود `summary` على كل أداة
- اختبار meta tool: search يطابق، details يرجع schema، list يرجع كل شيء
- اختبار التكامل (Integration): في وضع fullMode كل شيء كما كان؛ في الوضع التدريجي، disable/enable يعمل

## التوافق مع الإصدارات السابقة (Backward compat)

- `BROWSER_CONTROLLER_FULL_TOOLS=1` = السلوك الحالي تماماً (لا تغيير للمستخدمين الحاليين)
- الوضع الافتراضي الجديد = تدريجي، لكن الوكيل الذكي سيكتشف الأدوات بسرعة عبر browser_tools
- Hermes/Cursor/Zcode config يمكنه تعيين env var للوضع الكامل حتى يعتادوا

## لماذا هذا آمن

- الـSDK يدعم `enable()/disable()/sendToolListChanged()` بشكل أصلي
- `toolMap` موجود بالفعل (dead code) — لن نضيف imports جديدة
- الـdaemon/bridge/extension لا يتغيرون (tool names تمر كـopaque strings)
- الاختبارات الحالية (123) تبقى خضراء (السلوك المنطقي لا يتغير)
