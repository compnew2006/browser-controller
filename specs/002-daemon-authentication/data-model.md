# Data Model: Authenticate the Local Daemon

This feature adds only ephemeral in-memory protocol state; it does not change persisted user data or credential files.

## HTTP authentication challenge

| Field | Purpose | Validation |
|---|---|---|
| `clientNonce` | Fresh caller-generated value that ties the challenge to one attempt | Cryptographically random, fixed minimum/maximum encoded length, never reused by the caller |
| `serverNonce` | Daemon-generated challenge identifier | Cryptographically random; stored only until consumed or expired |
| `instanceId` | Identifies the daemon process issuing the challenge | Must match the value authenticated in the server proof |
| `serverProof` | Proves the responder knows the enrollment secret | Domain-separated HMAC over protocol version, client nonce, server nonce, and instance ID |
| `clientProof` | Authorizes one method and exact path/query | HMAC over both nonces, method, and canonical request target; verified once |
| `responseProof` | Authenticates a response body and status | HMAC over both nonces, response status, and hash of the exact response bytes |
| `createdAt` / `consumed` | Prevents replay and bounds challenge lifetime | Challenge expires after a short fixed window, is consumed on first valid operation, and registry has a hard capacity |

## WebSocket authentication state

| State / field | Purpose | Validation |
|---|---|---|
| `pending` | New socket before authentication | May send only one `authInit`; no tool, vault, ping, or response frame is handled |
| `clientNonce` | Fresh value generated by the extension for this socket | Random per socket and compared exactly in the response proof |
| `serverNonce` | Fresh value generated by the daemon for this socket | Random per socket, sent in the daemon `hello`, and held only by that socket's handler; a client proof from another socket never matches it |
| `daemonProof` | Authenticates the daemon to the extension | HMAC with enrollment secret over both nonces, daemon instance, version, and sorted capability set |
| `clientProof` | Authenticates the extension to the daemon | HMAC with auth token over both nonces, daemon instance, version, browser identity, and sorted capabilities |
| `ready` | Authenticated connection eligible for tool routing | Set only after both proof checks and existing version/capability validation pass |

No nonce, proof, or ready state is persisted across daemon or extension restarts.
